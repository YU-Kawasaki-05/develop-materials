# 第4章 プログラミングの基本：変数、関数、制御構造

## 🎯 この章で学ぶこと
- 変数がプログラム内でデータを保持する「箱」の役割を果たすことを理解する。
- 数値、文字列、真偽値といった基本的なデータ型の違いと用途を説明できる。
- 関数を使って、特定の処理を再利用可能な「部品」としてまとめることができる。
- `if`文（条件分岐）と`for`/`while`文（繰り返し）を使って、プログラムの流れを制御できる。
- 変数のスコープ（有効範囲）という重要な概念を理解する。

## 🤔 なぜ重要なのか
プログラミング言語は、コンピュータに指示を伝えるための「言語」です。そして、どんな言語にも基本的な文法や語彙があるように、ほとんどのプログラミング言語には共通の基本構成要素があります。それが**変数**、**関数**、そして**制御構造**です。

-   **変数**は、話で使う「代名詞（あれ、それ）」のように、データに名前を付けて扱うためのものです。
-   **関数**は、よく使う言い回しを「定型文」としてまとめるようなものです。
-   **制御構造**は、「もし〜ならば、〜する」「〜が終わるまで、〜を繰り返す」といった、話の流れを組み立てる接続詞のような役割を果たします。

これらの基本要素を理解することは、特定のプログラミング言語の文法を覚える以前の、もっと根源的な「プログラミング的思考」の土台を築くことです。この土台があれば、JavaScript、Python、Javaなど、どんな言語を学ぶ際にも、その習得スピードは格段に上がります。AIに「こういう機能を作って」と指示する際も、これらの基本要素を組み合わせて思考し、より正確で具体的な指示を生成できるようになります。

## 📚 基礎概念の理解

### 変数 (Variable)：データを格納する「箱」
プログラムが処理するデータ（数値、テキストなど）を一時的に記憶しておくための「名前付きの箱」です。箱に名前（変数名）を付け、中にデータ（値）を入れることで、後からその名前を使って中のデータを取り出したり、書き換えたりできます。

```python
# Pythonでの変数の宣言と利用
# 'age'という名前の箱を用意し、中に30という数値を入れる
age = 30

# 'name'という名前の箱を用意し、中に'Taro'という文字列を入れる
name = "Taro"

# 箱の中身をコンソールに出力する
print(name)  # -> Taro
print(age)   # -> 30

# 箱の中身を書き換える
age = 31
print(age)   # -> 31
```

### データ型 (Data Type)：箱の種類
変数という「箱」には、入れるデータによって種類があります。これをデータ型と呼びます。言語によって厳密さは異なりますが、代表的なものには以下があります。

-   **数値型 (Number/Integer/Float)**: `10`, `3.14`などの数値。計算に使います。
-   **文字列型 (String)**: `"Hello"`, `'Taro'`などのテキストデータ。シングルクォートまたはダブルクォートで囲みます。
-   **真偽値型 (Boolean)**: `True`か`False`のどちらかしか入らない型。「正しいか、間違っているか」を表現します。
-   **配列/リスト型 (Array/List)**: 複数のデータを順番に格納できる型。 `[1, 2, 3]`, `["Red", "Green", "Blue"]`など。
-   **オブジェクト/辞書型 (Object/Dictionary)**: キーと値のペアでデータを格納する型。`{"name": "Taro", "age": 30}`など。

### 関数 (Function)：処理をまとめる「道具」
一連の処理をひとまとめにし、名前を付けたものです。同じ処理を何度も書く必要がなくなり、プログラムが整理され、読みやすくなります。

-   **引数 (Argument/Parameter)**: 関数に渡すことができるデータ。関数がより柔軟になります。
-   **戻り値 (Return Value)**: 関数が処理を終えた後に返す結果。

```javascript
// JavaScriptでの関数の定義と利用

// 2つの数値を受け取り(引数 a, b)、合計を返す(戻り値)関数
function add(a, b) {
    const result = a + b;
    return result; // 結果を返す
}

// 関数を呼び出し、戻り値を変数に格納する
const sum = add(5, 3); // aに5, bに3が渡される
console.log(sum); // -> 8

const anotherSum = add(100, 200);
console.log(anotherSum); // -> 300
```
`add`という「道具」を作ったことで、足し算が必要なときはいつでもそれを呼び出すだけでよくなりました。

### 制御構造 (Control Flow)：プログラムの流れを操る
プログラムは通常上から下に順に実行されますが、制御構造を使うことで、その流れを操ることができます。

#### 1. 条件分岐 (Conditional)
`if`文は、「もし〜が真（True）なら、この処理を実行する」という条件分岐を作ります。

```javascript
// 年齢によってメッセージを変える
let age = 25;

if (age >= 20) {
    console.log("あなたは成人です。"); // ageが20以上なので、こちらが実行される
} else {
    console.log("あなたは未成年です。");
}
```

#### 2. 繰り返し (Loop)
同じ、あるいは似たような処理を何度も繰り返す場合に使います。

-   **`for`ループ**: 主に繰り返す回数が決まっている場合に使います。
    ```python
    # 0から4まで、5回繰り返す
    for i in range(5):
        print(f"現在の数字は {i} です。")
    
    # 配列の要素を一つずつ取り出して処理する
    fruits = ["apple", "banana", "cherry"]
    for fruit in fruits:
        print(fruit)
    ```

-   **`while`ループ**: ある条件が真（True）である限り、処理を繰り返します。
    ```python
    # カウンターが5未満の間、ループを続ける
    count = 0
    while count < 5:
        print(f"whileループ: {count}")
        count = count + 1 # カウンターを更新しないと無限ループになる！
    ```

## 💡 実践的な活用

### 良い変数名・関数名の付け方
-   **具体的で分かりやすい名前**: `x`や`tmp`のような曖昧な名前は避け、何のための変数・関数か分かるようにする。（例：`user_name`, `calculate_total_price()`）
-   **一貫した命名規則**: `userName`（キャメルケース）や`user_name`（スネークケース）など、プロジェクト内で命名規則を統一する。

良い命名は、AIがコードを生成・解析する際の精度を向上させる上でも極めて重要です。

### スコープ (Scope)：変数の有効範囲
変数がプログラムのどの部分から参照できるか、という範囲を**スコープ**と呼びます。
-   **グローバルスコープ**: プログラムのどこからでもアクセスできる変数。便利ですが、意図しない場所で書き換えられる危険性があり、多用は避けるべきです。
-   **ローカルスコープ**: 関数の中など、特定のブロック内で宣言された変数。そのブロックの外からはアクセスできません。

```javascript
let globalVar = "私はグローバルです";

function myFunction() {
    let localVar = "僕はローカルです";
    console.log(globalVar); // OK
    console.log(localVar);  // OK
}

myFunction();

console.log(globalVar); // OK
// console.log(localVar); // Error! 関数の外からはアクセスできない
```
スコープを理解することは、変数が衝突したり、意図せず書き換わったりするバグを防ぐために不可欠です。

## 🔍 深掘り：プロの視点

### 値渡し vs. 参照渡し
関数に変数を渡す（引数）とき、その渡され方には大きく2種類あります。
-   **値渡し (Pass by Value)**: 変数の中の「値のコピー」が渡される。数値や文字列、真偽値など、基本的なデータ型（プリミティブ型）で起こる。関数内で値を変更しても、元の変数には影響しない。
-   **参照渡し (Pass by Reference)**: 変数が指し示している「データの場所（アドレス）」が渡される。配列やオブジェクトで起こる。関数内でデータを変更すると、**元の変数の中身も変わってしまう**。

```python
# 参照渡しの例
def add_to_list(my_list):
    my_list.append(4) # 渡されたリストに要素を追加

numbers = [1, 2, 3]
add_to_list(numbers)
print(numbers) # -> [1, 2, 3, 4] 元のリストが変更されている！
```
この違いを知らないと、気づかないうちにデータを書き換えてしまう、という深刻なバグの原因になります。

### エラーハンドリング (try-catch)
プログラムは常に正常に動くとは限りません。ファイルが見つからない、ネットワークに接続できないなど、予期せぬエラーが発生することがあります。`try-catch`構文は、そうしたエラーに備えるための仕組みです。

-   `try`ブロック: エラーが発生する可能性のある処理をこの中に書く。
-   `catch`ブロック: `try`ブロック内でエラーが発生した場合に、この中の処理が実行される。

```javascript
try {
    // 存在しない関数を呼び出す（エラーを意図的に発生）
    nonExistentFunction();
} catch (error) {
    console.error("エラーが発生しました！");
    console.error(error); // エラーオブジェクトの詳細を表示
}

console.log("エラーが起きても、プログラムはここで止まらずに続く。");
```
堅牢なアプリケーションを作るには、適切なエラーハンドリングが必須です。
